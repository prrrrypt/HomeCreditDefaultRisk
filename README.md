# Home Credit Default Risk

An end-to-end credit risk analytics and machine learning
project using the Home Credit Default Risk dataset.

## Objectives
- Explore borrower characteristics and repayment risk.
- Engineer financial features using SQL and Python.
- Develop and evaluate credit risk prediction models.
- Explain model predictions and analyze decision thresholds.
- Build an interactive risk analytics dashboard.

## Tech Stack
Python, SQL, DuckDB, pandas, scikit-learn,
LightGBM, SHAP, Streamlit

## Dataset
Kaggle Home Credit Default Risk
